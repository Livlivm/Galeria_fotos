# Galeria 

Aplicativo desenvolvido em Flutter como atividade prática do curso de Desenvolvimento de Sistemas.

O projeto consiste em um aplicativo de cardápio digital, desenvolvido para facilitar a visualização dos produtos e proporcionar uma experiência simples e intuitiva ao usuário.

## Funcionalidades

* Tela de abertura (Splash Screen)
* Tela principal do aplicativo
* Visualização do cardápio
* Exibição dos produtos disponíveis
* Organização dos produtos por categorias
* Visualização das informações dos produtos
* Seleção de produtos
* Compartilhamento de informações
* Interface desenvolvida para dispositivos móveis

## Tecnologias utilizadas

* Flutter
* Dart
* Android
* share_plus

## Objetivo

O objetivo do projeto é desenvolver uma aplicação mobile utilizando Flutter, colocando em prática conceitos de desenvolvimento de interfaces, organização do código, navegação entre telas e utilização de recursos do dispositivo.

## Execução do projeto

Para executar o aplicativo, é necessário possuir o Flutter instalado e um dispositivo Android ou emulador configurado.

No terminal, dentro da pasta do projeto, execute:

```bash
flutter pub get
flutter run
```
